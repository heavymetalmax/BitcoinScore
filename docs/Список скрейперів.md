Список скрейперів

- `nupl` — Net Unrealized Profit/Loss (%) (BitcoinMagazinePro / BMP)  
- `mvrv_z_score` (`mvrv`) — MVRV Z‑score (BitcoinMagazinePro / BMP)  
- `profit_taking_ratio` (`profit_taking`) — відношення profit↔loss, похідний від `addresses_in_loss`  
- `addresses_in_loss` — % адрес в збитку (BitcoinMagazinePro / BMP)  
- `addresses_in_profit` — похідний показник (100 − `addresses_in_loss`)  
- `cvdd_ratio` — BTC price / CVDD, proximity до дна (BitcoinMagazinePro / BMP)  
- `rhodl_ratio` — RHODL Ratio, цикловий індикатор перегріву (BitcoinMagazinePro / BMP)  
- `rainbow_band` — Rainbow Chart band: поточний цикловий рівень ціни з назвою та кольором (BitcoinMagazinePro / BMP)  
- `m2_mom` — Global M2 YoY % (BitcoinMagazinePro Global Liquidity index; глобальний агрегат: Fed + ECB + PBoC + BoJ; збережено в `data/history/global_m2.json`; для свіжих місяців застосовується US WM2NS delta як proxy)  
- `dxy` — US Dollar Index / Broad Dollar Index (FRED, серія DTWEXBGS)  
- `geopolitical_risk` — глобальний індекс геополітичного ризику (Caldara & Iacoviello GPR XLS)  
- `fear_greed` — Fear & Greed index (BitcoinMagazinePro, Playwright live scrape; fallback: `data/history/fear_greed.json`, потім alternative.me API)  
- `btc_price` — поточна ціна BTC (CoinGecko)  
- `cipherb` — CipherB локальний індикатор (локально)  
- `smc` — SMC / price vs support (локально)
